## What is on the florist home screen?

On a computer the home screen shows three figures at the top:

- **Open Drafts**: how many of your orders are still drafts. Click it to see your draft orders.
- **Events This Week**: events whose event date (or delivery date, if there is no event date) falls in the current week.
- **Revenue This Week**: for orders in the current week, the wholesale cost of the flowers, rounded up to whole bunches, multiplied by your organisation's retail markup.

Below are three large cards, **Orders**, **New Order** and **Invoices**, and three smaller ones: **Explore Flowers**, **Settings** and **Help guides**, which opens the help site in a new tab. **New Order** opens the form for adding an event straight away.

**Where:** Home (florist landing page)

[Read more](/florists/florist-landing/)

## How do I start a new order?

1. Click **New Order** on the home screen. The **Add Event to Order** form opens on the **Event Order** tab.
2. Fill in **Name**, **Event Date**, **Location** and **Delivery / Pickup Date**. All four are required. **Preferred wholesaler** is optional. **Location** suggests venues from your own past events, and you can still type a new one.
3. Choose **Add and Edit** to go straight to the new event's page, or **Add to Order** to go to the weekly order it landed in.

You never create a weekly order by hand: StemCounts puts the event into the right week for you.

**Where:** Home > New Order, or an order's page > Add Event

[Read more](/florists/creating-your-first-event/)

## What is the difference between an Event Order and a Bunch Order?

The form has two tabs:

- **Event Order**: "A named event, on a date, at a venue." You give it a name, **Event Date**, **Location** and **Delivery / Pickup Date**, then build it from arrangements.
- **Bunch Order**: "Buy flowers by the bunch. No event, no arrangements." You only need a **Name** and a **Delivery / Pickup Date**. **Location** is optional ("if applicable").

A Bunch Order takes you straight into the Flower Picker, counting in bunches, so typing or picking 1 means one bunch rather than one stem.

**Where:** Add Event to Order form (Event Order and Bunch Order tabs)

[Read more](/florists/creating-your-first-event/)

## Can I create a Retail order?

Not as a separate order type at the moment. The Events and Retail switch on the Orders page is hidden, and **New Order** on the home screen always creates an event order.

If you want to buy stock for the shop rather than for a particular occasion, use the **Bunch Order** tab when adding an order. It is made for buying flowers by the bunch, with no event and no arrangements, and the location is optional.

**Where:** Orders

[Read more](/florists/creating-your-first-event/)

## Which weekly order does my event go into?

Orders are grouped by week. StemCounts looks at the week of your **Event Date** (for a Bunch Order, the **Delivery / Pickup Date**). If you already have a draft order for that week, the event is added to it. If not, a new draft order is created for that week.

To add another event to a week you already have open, click **Add Event** at the top of that order's page. The button only shows while the order is a draft. When you add from inside an order, the **Event Date** picker only offers days in that order's week.

**Where:** Add Event to Order form; order page > Add Event

[Read more](/florists/creating-your-first-event/)

## What is the difference between the event date and the delivery date?

**Event Date** is the day the event happens. **Delivery / Pickup Date** is "When the flowers are needed. Change it if they arrive earlier." You choose both when you add the event.

StemCounts fills in the delivery date for you (from the order's date, or the event date) but only when the field is blank, so a date you type is never overwritten.

You can change it later on the weekly order page with **Delivery/Pick Up Date:** in the summary header, and again per wholesaler when you send. Those pickers only allow dates from today up to the latest event date in the order (or the end of the order's week).

**Where:** Add Event to Order form; Weekly Order Summary

[Read more](/florists/creating-your-first-event/)

## What does Preferred wholesaler do on an event?

It is an optional starting point, not a lock-in. As the form says: "Every flower starts with this wholesaler. You can still change any of them later." Leave it on **No preference** if you have none.

Choosing one also means the event is counted in that wholesaler's bunch sizes where they have one, and the Flower Picker can tell you when a stem length you pick is not in their list.

**Where:** Add Event to Order form > Preferred wholesaler

## How do I edit or delete an event?

On the weekly order page, each event card has a **...** menu with **Edit** and **Delete**. On the event page you can also use the pencil (**Edit event details**) beside the event name.

**Edit Event Details** lets you change **Event Name**, **Event Date**, **Event Location** and **Price Markup for this Event**, then **Save Changes**. It opens on the event's own date, and the date is only checked (it must be tomorrow or later) when you change it, so renaming an event never moves it. If a new date falls in another week, the event moves to that week's order and opens there.

**Delete** asks you to confirm and cannot be undone. The menu disappears once the event has been sent. Deleting a whole weekly order is only available to StemCounts admins, and only while it is still a draft.

**Where:** Order page > event card > ... menu; Event page > Edit event details

## How do I add a note to the whole order?

While the order is a draft, click the speech-bubble icon next to the order reference (**Open order note**). The **Order Note** window says "Add a comment for the entire order." Type your note and click **Save note**. The icon fills in once a note is saved.

After the order is sent the note can no longer be edited. It is shown read-only in an **Order Note** panel at the top of the order.

**Where:** Order page > speech-bubble icon beside the order reference

[Read more](/florists/sending-your-order/)

## How do I add arrangements to an event?

1. On the event page click **Add Arrangement**.
2. In **Add Arrangements**, fill in a row for each design: **Name**, **Qty** (how many you are making) and **Budget** (per arrangement). **Total Budget** shows Qty times Budget. "All budget values are Ex GST".
3. Use **Add another arrangement** for more rows.
4. Click **Add Arrangement** (or **Add Arrangements**).

On a phone it is a step by step wizard: choose **From scratch** or **From a favourite**, give it a name, then set how many and the budget. **Save and create another arrangement** starts the next one, and **Add flowers** (or **Add flowers to all**) opens the flower picker.

If you leave a budget blank, StemCounts asks for it before adding. Adding the first arrangement to an event also creates the event's **Spares** bucket.

**Where:** Event page > Add Arrangement

[Read more](/florists/building-an-arrangement/)

## How do I change an arrangement's name, quantity or budget?

Edit them in place on the card while the order is a draft:

- Click the arrangement name to rename it.
- Click **Qty:** to change how many of this design you are making.
- Click the **$spent / $budget** figure ("Spent and Remaining - Click to edit your budget") to change the budget.

Press Enter to save or Escape to cancel. Flower quantities on the card are per arrangement. The total stems for the event are that number multiplied by **Qty**: 5 roses in an arrangement with Qty 12 is 60 roses. Hover a flower's number to see its total stems.

**Where:** Event page > arrangement card

[Read more](/florists/building-an-arrangement/)

## How do I pick flowers for one arrangement?

1. On an empty arrangement card click **Pick Flowers** ("Add flowers to this arrangement only"). The **Flower Picker** opens.
2. Click a colour dot under a flower to select that colour. Selected colours move up onto the photo. Click one there to deselect it.
3. Click **Add Selections** (the floating button at the bottom, with a count) to add them and return to the event.

Each colour you pick goes in as 1 stem (or 1 bunch in a bunches arrangement). Set the real quantities on the arrangement card afterwards. If a flower is already in the arrangement it is topped up rather than duplicated. **Back to Order Part** leaves without adding.

**Where:** Event page > arrangement card > Pick Flowers

[Read more](/florists/the-flower-picker/)

## How do I add the same flowers to every arrangement at once?

Click **Add Flowers** in the Arrangements header ("Add flowers to all arrangements"). It is available once the event has at least one arrangement. You can also click **Add Flowers to All** in the **Add Arrangements** window, which creates the new arrangements first and then opens the picker.

Every flower you pick is added to each arrangement in the event, except Spares: 1 stem each, or 1 bunch in a bunches arrangement. It is not divided between them. An arrangement that already holds that flower is topped up. If some arrangements already have flowers, StemCounts tells you before adding on top.

**Where:** Event page > Add Flowers; Add Arrangements > Add Flowers to All

[Read more](/florists/the-flower-picker/)

## How do the Flower Picker search and filters work?

- **Search**: "Search flowers by name, common name, or code...". It also matches colour names.
- **Categories**: narrow to one category, or **All Categories**.
- **Colours**: under **Pick colours**, choose one or more colours. The **Similar shades** switch (on by default) also includes colours close to the ones you pick. Turn it off for exact matches only.
- **Season**: show flowers in season in the months you choose.

Filters combine, and **Clear** resets colours or seasons. Pinned flowers always sort to the top.

**Where:** Flower Picker; Settings > Explore Flowers

[Read more](/florists/the-flower-picker/)

## How do I pin my favourite flowers?

In the Flower Picker, click the heart in the top-left corner of a flower's photo (**Pin flower**). Click it again to **Unpin flower**.

In **Explore Flowers**, open a flower and turn on **Pin to the top**: "Pinned flowers come first, here and when you pick flowers for an order."

Pinned flowers show before everything else, with the most recently pinned first. They stay pinned next time you open the picker, which suits staples you order every week.

**Where:** Flower Picker (heart on a flower photo); Settings > Explore Flowers

[Read more](/florists/the-flower-picker/)

## Why can't I find a flower in the picker?

A few things hide flowers:

- The picker only shows flowers, and colours, that at least one wholesaler currently offers.
- Colours already in the arrangement are taken off the card, and a flower disappears once all its colours are in. When adding to all arrangements, a colour is hidden only if every arrangement already has it.
- A search, category, colour or season filter is still on. Check **Similar shades** too.

If the page says **No flowers available**, try **Refresh Flowers**. If a wholesaler doesn't stock a flower you need, you can ask them to add it from the weekly order summary.

**Where:** Flower Picker

[Read more](/florists/the-flower-picker/)

## What price and bunch size does the picker show?

Each card shows **Price:** and **Stems per bunch:**. When you add flowers to an event that has a preferred wholesaler, it is that wholesaler's price and bunch size for the flower, which is the price the flower is costed at on the event. If that wholesaler does not list the flower, or the event has no preferred wholesaler, it is the catalogue price and bunch size. It is a wholesale price, not your customer price. In **Explore Flowers**, which is not tied to an event, the price is a range across wholesalers, for example "from $9.00 (5 stems) to $20.00 (10 stems)".

Hover over the name at the bottom of the photo for more: the other names, **Category**, **Price**, **Stems per bunch**, **Length** (if chosen) and **Season**.

**Where:** Flower Picker > flower card

[Read more](/florists/the-flower-picker/)

## How do I choose a stem length?

When a wholesaler lists a flower in more than one length, the card shows length pills such as **60cm** under the colours. Click one to choose it, and click it again to clear it.

Hover over a pill to see who lists that length and at what price. If your event's preferred wholesaler doesn't list it you can still pick it: the hover says "Not in [wholesaler]'s list" and names who does, and the line carries a note saying so.

A line at a length is kept separate from the same flower at another length. It shows the length next to its name and is rounded to whole bunches on its own.

**Where:** Flower Picker > flower card > length pills

[Read more](/florists/the-flower-picker/)

## How do I change flower quantities in an arrangement?

Each flower row on a card has:

- small up and down arrows (**Increase quantity**, **Decrease quantity**),
- the number itself. Click it ("Click to change number") to type a new amount, then press Enter.
- an **X** (**Remove from this list**) to take the flower out.

After you remove a flower, an **Undo** button shows for five seconds before the removal is saved.

In a normal arrangement the number is stems per arrangement. In a bunches arrangement it is bunches, and the arrows move one bunch at a time. Once the order is sent, quantities are read-only.

**Where:** Event page > arrangement card > flower row

[Read more](/florists/building-an-arrangement/)

## Can I order in bunches instead of stems?

Arrangements normally count stems. To count in bunches inside an event, click the bouquet button beside **Add Flowers** ("Add a Bunches arrangement"). **Add Bunches Arrangement** asks for a **Name** and **Budget**.

In a bunches arrangement, each picked flower goes in as one bunch, quantities show as bunches, and hovering the number shows "N bunches (M stems)". There is no switch to turn an existing stems arrangement into bunches, so add a Bunches arrangement instead.

For buying purely by the bunch with no event, create a **Bunch Order**.

**Where:** Event page > bouquet button (Add a Bunches arrangement); Bunch Order

[Read more](/florists/the-flower-picker/)

## How does a Bunch Order work once it's created?

A Bunch Order has one **Flowers** list instead of arrangement cards. Each row has a photo and shows "N stems per bunch" (or **Sold per stem**), the total stems and the price per bunch. The **+** and **-** buttons step in whole bunches.

At the top, **Add Flowers** opens the picker in bunch mode. **Favourites** copies in a saved favourite that is marked for bunches. **Set a budget** records your budget.

There is no Summary or Spares panel because everything is already whole bunches. Click **Add to Weekly Order** when you are ready.

**Where:** Bunch Order page (Flowers list)

## How is the bunch rounding worked out on the event page?

The **Summary** panel adds up each flower across every arrangement and Spares, including arrangement quantities, and compares it with the bunch size.

- **Unrounded Bunches**: flowers that don't come to a whole number of bunches (part bunches). Each row has a red **Remove** button showing the extra stems, and a teal **Add** button showing the stems needed to complete the bunch.
- **Rounded Bunches**: flowers that are whole bunches, with a tick.

**Add** puts the missing stems into Spares. **Remove** takes the extra stems back out of your arrangements. If a flower has no whole bunch at all, you are asked to confirm removing it from the event.

**Where:** Event page > Summary panel

[Read more](/florists/the-spares-bucket/)

## What is the Spares bucket and how do stems get into it?

**Spares** holds stems left over from rounding up to full bunches. Every event with arrangements has one, shown after your arrangements. It has no **Pick Flowers** button. Stems get in these ways:

- The **Add** (+N) button in the Summary's **Unrounded Bunches** table ("Add any spares to the bucket using the arrow in the summary.").
- Dragging a flower from an arrangement onto Spares.
- Automatically: when you change a flower's quantity in an arrangement and that flower already has a spares line, the line is reset to exactly what completes the bunch. If nothing is needed, it is removed.

Spares are ordered from the wholesaler with everything else and count towards the event's total spend.

**Where:** Event page > Spares card

[Read more](/florists/the-spares-bucket/)

## How do I remove stems from Spares?

Quantities in Spares can't be typed in. Each spare row has two small buttons instead:

- **X** (**Remove these stems from Spares**) removes that row outright. The same **Undo** as other rows appears briefly before the removal is saved.
- The two-way arrows (**Reallocate these stems**) move the stems into your arrangements instead.

After removing spares, that flower may no longer be whole bunches. Check the **Summary** panel before adding the event to the weekly order.

**Where:** Event page > Spares card > X on a row

[Read more](/florists/the-spares-bucket/)

## How do I move spare stems into an arrangement?

1. On a spare row, click the two-way arrows (**Reallocate these stems**).
2. **Move spare stems into your arrangements** lists every arrangement in the event. Use each card's stepper to set how many stems go in. An arrangement without that flower yet can still receive it ("Not in this arrangement yet, moving stems in adds it").
3. Click **Move N stems**.

For an arrangement made several times (Qty above 1), stems move that many at a time, one into each. You can't move more than are in Spares. Any leftovers that can't be placed stay in Spares, and the window tells you so.

**Where:** Event page > Spares card > Reallocate these stems

[Read more](/florists/the-spares-bucket/)

## How do I move or copy a flower between arrangements?

While the order is a draft, drag a flower row from one arrangement card and drop it on another arrangement, or on Spares. **Transfer Flower** opens:

- **Copy stems**: "Add stems to the target bucket (keep source unchanged)". Enter how many **Stems** to copy.
- **Move all**: "Move all available stems to the target bucket".

If the target already has that flower, the stems are added to its existing line. You can also drag whole arrangement cards to reorder them, though Spares always stays at the end.

**Where:** Event page > drag a flower row onto another card

## How do I clone an arrangement?

1. Click the three dots on the arrangement card (**More actions**).
2. Click the copy icon (**Clone**).

A new arrangement called "[name] (Copy)" appears after your other arrangements. It has the same **Qty**, budget and flower list with the same quantities. Per-flower markup overrides and chosen stem lengths are not carried onto the copy.

Rename the copy by clicking its name. Clone works within the same event, and only while the order is a draft.

**Where:** Event page > arrangement card > More actions > Clone

[Read more](/florists/cloning-arrangements/)

## How do I delete an arrangement?

Click the three dots on the card (**More actions**), then the bin icon (**Delete**). **Delete arrangement** asks you to confirm. If the arrangement has flowers it warns "This will also delete all flowers in this arrangement." The action cannot be undone.

You can only delete while the order is a draft. After sending, the window says "This arrangement cannot be deleted because the order has been sent."

**Where:** Event page > arrangement card > More actions > Delete

[Read more](/florists/cloning-arrangements/)

## How do I save and reuse favourite arrangements?

- **Save**: open the card's three dots and click the star (**Save as favourite (with its flowers)**). The arrangement needs a budget first.
- **Reuse**: on an empty arrangement, click **Fill with a Favourite** and pick one. Its flowers are copied in. "Prices are today's, not the prices when the favourite was saved."
- In **Add Arrangements**, a star beside a typed name saves it as a favourite, and your saved favourites appear there to add in one click.

Manage them under **Settings > Ordering > Favourite Arrangements**.

**Where:** Arrangement card > More actions > Save as favourite; empty card > Fill with a Favourite; Settings > Favourite Arrangements

## How do budgets and the budget bar work?

An arrangement's budget is your customer price for one of that design, ex GST. The event header adds up budgets multiplied by quantities, and its **Spent** includes Spares.

Switch between **Wholesale** (your cost) and **Customer** (cost plus markup). **Flower Profit** is the customer budget minus your cost.

The info button (**How these numbers work**) explains that **Remaining** compares your customer price with the budget, while profit compares the budget with your cost, so you can be over budget and still profitable. Going over budget never blocks you.

**Where:** Event page header and arrangement cards

[Read more](/florists/pricing-and-budgets/)

## Where do I set my retail markup?

Go to **Settings > Your Organisation** and click **Retail markup**. It is a multiplier, not a percentage: "The multiplier applied to wholesale costs when pricing for your customers. Example: 3 x $10 = $30." Values snap to the nearest 0.25, and the row shows it as, for example, "3 x cost".

This is your default for every event. You can override it for one event, or for one flower line. Markup only changes your customer-side figures. The wholesale cost always comes from the wholesaler.

**Where:** Settings > Your Organisation > Retail markup

[Read more](/florists/pricing-and-budgets/)

## Can I use a different markup for one event?

Yes. Open **Edit Event Details** from the pencil beside the event name (or **Edit** on the event card). Enter a multiplier in **Price Markup for this Event**, for example 3.5, then click **Save Changes**. Values snap to the nearest 0.25.

Leave the field empty to go back to your default markup from Settings. The hint shows your default as a worked example on $10.

Customer prices for the event then use this markup, unless a flower line has its own override.

**Where:** Event page > Edit event details > Price Markup for this Event

[Read more](/florists/pricing-and-budgets/)

## Can I change the price of one flower?

You can change the markup on one flower line, which changes its customer price. The wholesale price can't be changed.

While the order is a draft, click the flower's name on an arrangement card. A card shows **Wholesale / bunch** and **Customer / bunch**. Enter a multiplier in **Markup override** and click **Save**. Use **Clear override** to go back to the event or default markup.

A flower with its own markup shows its name in coral, and hovering shows "Markup: Nx (this stem)".

**Where:** Event page > arrangement card > click the flower name

[Read more](/florists/the-flower-picker/)

## Are prices and budgets with or without GST?

Budgets are entered without GST. The arrangement screens say "All budget values are Ex GST", so enter the ex GST figure you would quote your client for that design.

The budget, spend and profit figures on the event and order pages are worked out from those ex GST budgets and the wholesale prices your wholesalers list, so treat them as ex GST figures too.

**Where:** Add Arrangements; missing budget prompt

[Read more](/florists/pricing-and-budgets/)

## Why is Add to Weekly Order greyed out?

**Add to Weekly Order** takes you from the event to its weekly order, ready to send. It stays greyed out until every flower in the event's **Summary** is whole bunches. Hovering it says "Allocate all spares before adding to the weekly order."

To fix it, clear the **Unrounded Bunches** table: use **Add** to top part bunches up into Spares, or **Remove** to trim the extra stems. Bunch Orders don't have this check. Once the order has been sent, this button becomes **Download PDF**.

**Where:** Event page > Add to Weekly Order

[Read more](/florists/the-spares-bucket/)

## How do I choose a wholesaler for my flowers?

On the weekly order page, the **Weekly Order Summary** lists every flower in the order.

- **Wholesaler:** in the header sets a wholesaler on every row they stock ("Apply to eligible flowers").
- Each row also has its own wholesaler list, showing each wholesaler's price. **Select wholesaler** clears the row.
- A row with no wholesaler is shaded yellow. A row showing **Default** has no wholesaler offering that flower.

A preferred wholesaler set on the event is filled in to start with. You can use different wholesalers for different flowers.

**Where:** Order page > Weekly Order Summary > Wholesaler

[Read more](/florists/sending-your-order/)

## Why did my bunches change when I picked a wholesaler?

Wholesalers don't all sell a flower in the same bunch size. When you choose a wholesaler, each row is recounted in that wholesaler's bunch size and priced at their price. If your stems no longer make whole bunches, a **Not whole bunches** window lists each flower with the extra stems and what they cost at that wholesaler's price. Pick one:

- **Round up** (it shows the stems and the total cost) adds the missing stems to Spares on the event.
- **Choose another wholesaler** closes the window so you can pick a different one.
- **Remove the extra stems** opens the event on its Bunches tab to trim them.

A part bunch cannot be sent, so **Send Order** stays disabled until it is sorted. On a phone, the button at the bottom of **Review and send** reads **Round up** until every line is whole bunches.

**Where:** Order page > Weekly Order Summary

[Read more](/florists/sending-your-order/)

## Can I tell the wholesaler something about one flower, or ask them to stock it?

**Comment on a flower:** while the order is a draft, click a row in the **Weekly Order Summary** to open **Comment for wholesaler**. Type your note and click the tick (**Save comment**). Comments are also saved when you send.

**Missing flower:** if the wholesaler you chose doesn't carry a flower or colour, its cell shows an amber warning, and a **Request missing flower** button appears in the header. The request window previews the message, takes an optional note and sends it to that wholesaler, with you copied on the email.

**Where:** Order page > Weekly Order Summary > flower row

[Read more](/florists/sending-your-order/)

## How do I send my order to the wholesaler?

**Send Order** turns on once every row has a wholesaler and every row is whole bunches.

1. Click **Send Order**.
2. **Send Assigned Orders** lists each wholesaler you've used. For each one, set the **Delivery/Pick Up Date** and **Fulfilment type** (**Delivery** or **Pick up**).
3. Click **Send Order**.

Each wholesaler gets their own order, emailed to them with your order contact copied in. If you filtered the summary to certain events with the eye icon on the event cards, only those events are sent.

**Where:** Order page > Weekly Order Summary > Send Order

[Read more](/florists/sending-your-order/)

## Will the wholesaler get a text message when I send?

Only if StemCounts has order text messages switched on. When they are on, sending an order texts the wholesaler a link to view and accept it, texts you that it went, and texts you again when the wholesaler accepts.

When they are off, the order is still emailed and still shows up as an in-app notification, so nothing is lost. Either way the email is the main record of the order.

**Where:** Sending an order

## What can I still change after sending?

Once the order is sent, the order and event pages become read-only:

- no adding, cloning or deleting arrangements, and no changing flowers, quantities, budgets or markups,
- no **Add Event**, and the event **Edit** and **Delete** menu is gone,
- the order note and flower comments can no longer be edited,
- the wholesaler lists become plain wholesaler names.

An event whose flowers have all been sent is locked even if the rest of the order is still a draft. For a change after sending, contact your wholesaler.

**Where:** Order page and Event page after sending

[Read more](/florists/sending-your-order/)

## How do I print or save an event sheet as a PDF?

Once an order is sent, click **Download PDF** on the event page, or the printer icon (**Print event details**) on the event in the Orders calendar. Then click **Download Order** to open your browser's print window, where you can print or save as PDF. **Close & Back** returns you to the app.

The sheet contains:

- **Event Details**: name, dates, week, location and wholesaler.
- **All Flowers**: stems and bunches (rounded up).
- **Comments**.
- **Arrangements**: each one's quantity, per-arrangement and total stems ("N each (M total)") and flower notes, with Spares last.

It shows no prices. Draft events can't be printed yet.

**Where:** Event page > Download PDF; Orders calendar > printer icon

[Read more](/florists/event-details-and-printing/)

## Can I use StemCounts ordering on my phone?

Yes, from start to finish. The **Orders** list leads with each event's name and has a search box. On an order, tap **Add event** in the bottom bar to add an event. On an event, set budgets, add arrangements with the step by step wizard and add flowers from the flower picker. Tap an arrangement to see its flowers and type stem counts. The **Bunches** tab shows the flowers still to round up, with minus and plus buttons.

When it is ready, the bar at the bottom of the event says **Review and send order**. That sheet shows the event, a **Delivery** date (the calendar rings the event date in teal and delivery or pickup dates in amber), a **Wholesaler**, and each flower's bunches and stems, then sends the order. There is no PDF button on a phone.

**Where:** Home, Orders, order and event pages on a phone

## What are the Calendar and Order Board views on the Orders page?

On a computer, the Orders page banner shows **Sent Order Value**, **Draft Orders** and **Sent Orders**, and has two switches:

- **Calendar** ("View orders in the weekly calendar planner.") or **Order Board** ("View orders grouped by status.").
- **Orders** or **Events**: whether cards are whole weekly orders or individual events.

The Order Board has four columns: **Draft**, **Sent**, **In Progress** and **Done**. The add button on the **Draft** column starts a new draft order for next week. In **Events** view, a draft event opens its event page and other events open their order.

**Where:** Orders
