If two arrangements share most of their flowers, clone one instead of
rebuilding it. Clone works within the same event, and only while the
order is a draft.

<HelpMedia id="arrangement-3-dot-menu" caption="The More actions menu on an arrangement card" />

## How to clone

<Steps>

1. Open the event with the arrangement you want to copy.

2. Click the three dots on the arrangement card (**More actions**).

3. Click the copy icon (**Clone**).

4. A new arrangement called "[name] (Copy)" appears after your other
   arrangements. It has the same **Qty**, budget and flower list with the
   same quantities.

5. Click the copy's name to rename it, and adjust **Qty**, budget or
   flowers as you would on any card.

</Steps>

## What clone copies

| Copied | Not copied |
|---|---|
| The flower list, with quantities | Per-flower markup overrides |
| The budget | Chosen stem lengths |
| **Qty** | |

## Reusing a design on another event

Clone stays inside one event. To use a design on a different event, in
any week, save it as a favourite: the star in the same menu, **Save as
favourite (with its flowers)**. Then fill an empty arrangement on the other
event with **Fill with a Favourite**. See
[Favourite arrangements](/florists/favourites/).

## Deleting

The same menu has a bin icon (**Delete**). **Delete arrangement** asks you
to confirm, and if the arrangement has flowers it says they will be
deleted with it. The action cannot be undone.

You can only delete while the order is a draft. After sending, the window
says the arrangement cannot be deleted because the order has been sent.
