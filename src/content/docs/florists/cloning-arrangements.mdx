If two arrangements share most of their flowers — e.g. five identical
centerpieces — clone instead of rebuilding.

<HelpMedia id="arrangement-3-dot-menu" caption="The 3-dot menu on an arrangement card" />

## How to clone

<Steps>

1. Open the event with the arrangement you want to copy.

2. Click the **3-dot menu** on the arrangement card (top-right of the
   card).

3. Click **Clone**.

   <HelpMedia id="arrangement-clone-action" kind="video" />

4. A new arrangement appears immediately below the original. By default
   it copies:

   - The full flower list (every stem, every colour, every quantity)
   - The budget
   - The quantity

5. Click the new arrangement to rename it and adjust budget or
   quantity if needed. Then **Pick Flowers** to tweak the stem list.

</Steps>

## What clone copies vs not

| Copied | Not copied |
|---|---|
| Flower list | Substitutions you've requested |
| Budget | Photos / files attached |
| Quantity | Notes that reference the original by name |

## Cloning across events

Cloning works **within** an event. To copy a design to a different
event in another week:

1. Clone the arrangement (in the original event)
2. Open the destination event
3. Manually recreate the arrangement using the cloned one as a reference
   (or use **Add Arrangement** with the same name and rebuild)

There's no cross-event clone today.

<Aside type="tip">
If you regularly run a "house" arrangement (always the same composition),
build it once and clone it each week. Faster than rebuilding from scratch.
</Aside>

## Deleting

The same 3-dot menu has a **Delete** option. Deletes are confirmed and
not recoverable — the arrangement and its stem list are gone. The
flowers freed up are not auto-added back to the Spares Bucket; the
budget is freed.
