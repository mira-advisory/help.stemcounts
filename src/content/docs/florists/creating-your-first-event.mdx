In StemCounts an **event** is one piece of work: a wedding, a corporate
job, a funeral, on a date, at a venue. Events live inside **weekly
orders**. You never create a weekly order by hand. You add an event, and
StemCounts puts it into the right week for you.

## Add an event

<Steps>

   opens on the **Event Order** tab. On a phone, tap **New order** on
   **Home** or the raised **New order** in the bar along the bottom, and
   the **New event** sheet opens on its **Event** page.

## Event Order or Bunch Order

The form has two tabs.

| Tab | What it is for | What you fill in |
|---|---|---|
| **Event Order** | "A named event, on a date, at a venue." You build it from arrangements. | **Name**, **Event Date**, **Location**, **Delivery / Pickup Date** |
| **Bunch Order** | "Buy flowers by the bunch. No event, no arrangements." | **Name** and **Delivery / Pickup Date**. **Location** is optional. |

A Bunch Order takes you straight into the Flower Picker, counting in
bunches. See [Bunch orders](/florists/bunch-orders/). There is no
separate retail order type: if you are buying stock for the shop rather
than for an occasion, use the **Bunch Order** tab.

## Event date and delivery date

**Event Date** is the day the event happens. **Delivery / Pickup Date**
is when the flowers are needed. You choose both. Change the delivery date
if the flowers should arrive earlier.

You can change the delivery date later on the weekly order page, with
**Delivery/Pick Up Date:** in the summary header, and again for each
wholesaler when you send. Those pickers only allow dates from today up to
the latest event date in the order (or the end of the order's week).

## Which weekly order the event goes into

Orders are grouped by week. StemCounts looks at the week of your **Event
Date** (for a Bunch Order, the **Delivery / Pickup Date**). If you already
have a draft order for that week, the event is added to it. If not, a new
draft order is created for that week.

To add another event to a week you already have open, click **Add Event**
at the top of that order's page. The button only shows while the order is
a draft. When you add from inside an order, the **Event Date** picker only
offers days in that order's week.

## Preferred wholesaler

It is a starting point, not a lock-in. As the form says: "Every flower
starts with this wholesaler. You can still change any of them later."

Choosing one also means the event is counted in that wholesaler's bunch
sizes where they have one, the Flower Picker shows their price and bunch
size for each flower, and the picker can tell you when a stem length you
choose is not in their list.

## Editing or deleting an event

On the weekly order page, each event card has a **...** menu with **Edit**
and **Delete**. On the event page you can also use the pencil (**Edit
event details**) beside the event name.

**Edit Event Details** lets you change **Event Name**, **Event Date**,
**Event Location** and **Price Markup for this Event**, then **Save
Changes**. The date is only checked when you change it (it must be
tomorrow or later), so renaming an event never moves it. If a new date
falls in another week, the event moves to that week's order and opens
there.

**Delete** asks you to confirm and cannot be undone. The menu disappears
once the event has been sent.

<Aside type="tip">
On a phone, tap **Add event** in the bar at the bottom of an order to add
an event to it.
</Aside>
