There are two printable versions of an order. The **order PDF** is the
picking document, with no prices. The **printable order page** is an A4
page that includes prices and the order total. Both cover one order at
a time.

## The order PDF

The order PDF lists the flowers with their stem and bunch counts. It
deliberately shows no prices, so it can go straight to whoever picks
the order.

You can get it three ways:

- Attached to the **New order** email
- From the printer icon beside the order reference in the order
  window (**Download order PDF**)

  <HelpMedia id="print-desktop-01-printer-icon" caption="The printer icon beside the order number downloads this order as a PDF pick list." />
- From **Download PDF** on the shared order page that the email's
  **View the order** button opens

On a phone, open the order and tap **Order PDF** under **More**.

## The printable order page

<HelpMedia id="print-desktop-04-printable-page" caption="The printable order page: an A4 sheet with every line, bunch counts and the total. Use your browser's print to paper or PDF." />

The printable order page shows the order reference, the florist's
details, the delivery or pickup date, any order note, and a table of
**Name**, **Colour**, **Quantity**, **Bunches** and **Price** with the
total value. Use your browser's print to print it on paper or save it
as a PDF.

<Aside type="tip">
For a printout without prices, use the order PDF instead.
</Aside>

## What is not on either document

- The supplier for each flower (that shows in the order's Inventory
  List)
- Platform fees
- Invoice or payment details (see the **Invoices** card on your home
  page)
